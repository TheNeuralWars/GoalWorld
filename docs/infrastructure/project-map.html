What the codebase says

Webapp

Contains React hooks/contexts/components and a marketing/play navigation layer. It is the user-facing layer that mounts gameplay and dashboard surfaces.

API

Exposes pipeline/marketing endpoints and integrates with social tooling. The source tree includes test helpers for Twitter/Grok integration and a pipeline health route.

Contracts

Anchor-based Solana programs and scripts for minting/token operations. This is the on-chain authority layer for protocol actions.
