Worker architecture

High-leverage refactor targets

Navigation

Route groups can be split into public / play / ops / collectible layers for faster cognitive navigation.

State boundaries

User, language, wallet, and game bus are good candidates for explicit domain boundaries.

Feature islands

Simulation, DeFi, staking, and marketing control are distinct product areas and can be mapped separately.

Route ownership

App.tsx currently owns all route declarations; extracting route manifests would make the shell easier to evolve.
